What our host records

Like every website, the server that delivers these pages keeps ordinary technical logs — the internet address a request came from, the time, which file was requested, and what browser asked for it. That happens automatically at the hosting layer and is standard for all web traffic. Those logs keep the site running and secure, are kept only briefly by the host, and are not used by McLearn Media to build a profile of you or to market to you.

Cookies

We set none. Some pages remember small conveniences in your own browser's local storage — which panel you hid, which teaching scenario you answered. That data never leaves your device, we cannot read it, and clearing your browser data removes it.

Fonts

Typefaces load from Google Fonts. When they load, Google receives the request and can see the internet address it came from, as with any external file. We send Google nothing about you beyond that request. A browser that blocks third-party requests will simply show a default typeface, and everything still works.
